


###  this folder is mostly for AI / LLM engines for documenting:

- feature additions 

- bug fixes 

- general findings (code structure, call-dependencies, etc.)

- TODO lists

- renamings, add a short simple note (no full story)



###  suggestions

- prepend a timestamp (YYYY-MM-DD) to each edit. 

- use markdown for basic formatting 

- introduce sections with `###  topic`

- use backticks for code blocks 

- be less verbose, but still precise

- do not describe old or modified states, just describe the new and current state of code/namings
